# REST API Project

This REST API is part of my training at Udemy. It is built using Node.js and Express, following an N-tier architecture (organized into layers). The API provides functionalities to:

- Get all users (`getUsers`)
- Add a user (`addUser`)
- Retrieve a specific user
- Update a user
- Delete a user

The API manipulates JSON objects and can be tested locally using tools like Postman or Insomnia.

This is the back-end of the project. To view the front-end part, visit: [Simple Client](https://github.com/OuidadM/Simple_Client).
